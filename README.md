FSD‑1 Experiment 2 – Clubbed Experiments
This repository contains the clubbed implementation of all tasks from Experiment 2 of the Full Stack Development‑1 lab.
All individual mini‑experiments (such as basic HTML pages, CSS styling tasks, and JavaScript DOM programs) are integrated into a single, organized web project for easier navigation and evaluation.
​

Tech Stack
HTML for page structure and content.

CSS for layout and visual styling.

JavaScript for DOM manipulation, user interactions, and basic validations
Project Structure
index.html – Main entry page providing navigation to all Experiment‑2 tasks.

bank-ui/index.html, bank-ui/script.js, bank-ui/style.css – Simple bank interface for deposit and withdraw functionality.

Other experiment folders (e.g., exp2-task1/, exp2-task2/, etc.) – Additional pages required for Experiment‑2, each linked from the main index.
